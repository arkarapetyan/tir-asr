# Eval recording scripts (D-019)

**Chat:** C1 · **Date:** 2026-10-24 · **Language:** Eastern Armenian (D-013)

## How to record

- **Format:** WAV (PCM, 16-bit) or FLAC. Both are lossless. Do not convert a lossless file to MP3 or M4A.
- **Phone apps that save only M4A (or a different lossy format):** keep the original file. Do not convert it. The program converts it one time.
- **Sample rate:** the default of the device (44.1 kHz or 48 kHz) is correct. The minimum is 16 kHz. Use mono if the device allows it. The program resamples to 16 kHz mono (D-019).
- **One file for each take:** record a full script as one continuous file, with all speakers. Leave a natural pause of about 1 s between turns. Do not speak at the same time.
- **Labels:** for each audio file, make a label file with the start time, the end time, and the line ID of each turn (for example, an Audacity label track exported as text). Line ID format: `s1-03` = script 1, line 3.
- **File names:** `data/eval/<script>_<device>_<take>.<ext>`, for example `data/eval/s1_phone_take1.wav` and `data/eval/s1_phone_take1.txt` (labels).
- **Folder:** keep all audio in `data/`. `data/` is in `.gitignore`. Note: `*.m4a` is not in the `.gitignore` patterns, so do not put audio files outside `data/`.
- **Devices:** record each script on two or more devices (for example, a phone and the laptop microphone).
- **Call path:** later (C4), a script plays the finished files through a real call and records the monitor source.
- **Changes:** if a speaker says different words, change the Armenian reference to the words in the audio.
- **Speaker labels:** "Me" is the person on the microphone side in the call tests. "Speaker 1", "Speaker 2" are the other people, in the order of their first line. The names inside the text stay, because they are words in the audio.
- † marks a line with «նա». Where the text does not show the gender, the English reference says "he/she".
- Read text is less natural than free talk. If there is time, also record 2–3 minutes of free talk and write its reference after.
